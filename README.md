# Anuja Bandara — AI & Data Analyst

Personal portfolio website for **Anuja Bandara**, a data analyst and AI systems builder based in Colombo, Sri Lanka.

The site presents experience, selected case studies, technical skills, education, and contact information across business intelligence, data engineering, geospatial visualization, machine learning, and LLM/RAG systems.

## Live website

Visit the portfolio at [SinethB.github.io](https://sinethb.github.io/).

## Highlights

- Responsive single-page portfolio built with semantic HTML, CSS, and vanilla JavaScript
- Dark, data-focused visual design with responsive layouts
- Interactive animated hero visualization rendered with HTML Canvas
- Scroll progress indicator and active section navigation
- Mobile navigation menu
- Scroll-triggered reveal animations
- Accessible focus styles and reduced-motion support
- Sections for:
  - About
  - Experience
  - Projects
  - Technical skills
  - Work approach
  - Education and achievements
  - GitHub repositories
  - Contact
  - Résumé download

## Featured projects

The portfolio showcases selected work including:

- **Production RAG Chatbot & Agent Pipelines** — retrieval-augmented generation and LangGraph agents
