# Anuja Bandara — AI & Data Analyst

Personal portfolio website for **Anuja Bandara**, a data analyst and AI systems builder based in Colombo, Sri Lanka.

The site presents experience, selected case studies, technical skills, education, and contact information across business intelligence, data engineering, geospatial visualization, machine learning, and LLM/RAG systems.

## Live website

Visit the portfolio at [SinethB.github.io](https://sinethb.github.io/).

## Highlights

- Responsive single-page portfolio built with semantic HTML, CSS, and vanilla JavaScript
- Dark, data-focused visual design with responsive layouts
- Interactive animated hero visualization rendered with HTML Canvas
- Scroll progress indicator and active section navigation

## Run locally

Because this is a static website, no build process or package installation is required.

1. Clone the repository:

   ```bash
   git clone https://github.com/SinethB/SinethB.github.io.git
   cd SinethB.github.io
   ```

2. Open `index.html` in a browser, or serve it locally with any static web server:

   ```bash
   python -m http.server 8000
   ```

3. Open [http://localhost:8000](http://localhost:8000) in your browser.

## Customization

- Update personal information, project details, and links in `index.html`.
- Add a `resume.pdf` file to the repository to enable the résumé download button.
- Replace placeholder contact and social links with current details.
- Update the GitHub project links in the GitHub section as repositories change.

## Deployment

This repository is configured for GitHub Pages. Changes pushed to the `main` branch can be published through the repository's **Settings → Pages** configuration.
